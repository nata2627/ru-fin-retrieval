# ru-fin-retrieval

Поисковый слой RAG по нормативным актам Банка России и измерение его качества.

Проект про **измеримое качество поиска**: набор размеченных запросов, сравнение
конфигураций на одних данных, доверительные интервалы, разбор провалов.
Демонстрационного чат-интерфейса здесь нет и не планируется.

## Состояние

Этап 1 из 4 — источники проверены, объём корпуса оценён.
Отчёт: [docs/01-istochniki.md](docs/01-istochniki.md).

- [x] источник проверен, объём и время сбора оценены
- [ ] корпус собран, набор запросов размечен, базовая линия BM25 посчитана
- [ ] четыре конфигурации и абляции измерены
- [ ] README, разбор ошибок, блок для резюме

## Коротко о главном на сегодня

Содержательные акты Банка России — Положения, Инструкции, Указания —
выложены отдельными файлами в виде **сканов с испорченным слоем распознавания**:
кириллица подменена латиницей, и подмена необратима. Из выборки в 10 таких
файлов пригоден 1.

Те же акты в **«Вестнике Банка России»** набраны в цифре: из выборки в 10
выпусков пригодны 10, доля кириллицы 99–100%. Корпус строится из «Вестника».

Подробности и числа — в отчёте этапа 1.

## Запуск

Нужны Python 3.11+ и `pdftotext` из poppler (`brew install poppler`).

```bash
pip install -r requirements.txt
make probe          # разведка источников, ~5 минут
make probe REFRESH=1  # с перекачкой перечней документов
```

## Устройство

```
src/rufin/
  http.py              вежливый клиент: последовательно, с паузой
  pdftext.py           извлечение текста и оценка пригодности слоя
  sources/
    cbr_lawacts.py     раздел «Правовые акты» (метаданные)
    cbr_vestnik.py     «Вестник Банка России» (основной источник)
scripts/
  probe_sources.py     разведка источников
data/index/            перечни документов (в репозитории)
data/raw/              скачанные PDF (в репозиторий не попадают)
docs/raw/              сырой вывод прогонов: все числа в отчётах взяты отсюда
```

Сырые выгрузки сайтов в репозитории не хранятся — только скрипт сбора
и перечни документов.
