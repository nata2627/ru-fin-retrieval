# Индексация корпуса на Kaggle

Что это. Поиск по корпусу требует один раз прогнать все фрагменты через
модель-эмбеддер и получить матрицу векторов. На MacBook Air это занимает
часы, на видеокарте Kaggle — минуты. Дальше матрица лежит файлом, и поиск
работает на ноутбуке без всякой видеокарты.

## Как запустить

1. Создать на Kaggle приватный датасет и загрузить в него содержимое этой
   папки: `acts.jsonl.gz`, `chunking.py`, `model_specs.py`, `index_kaggle.py`.
   Назвать датасет `ru-fin-retrieval`.

2. Создать ноутбук, подключить датасет, включить ускоритель **GPU T4 x2**
   (или P100 — разницы для этой задачи нет, работает одна карта).

3. Выполнить в ноутбуке:

   ```python
   !pip install -q -U sentence-transformers
   !cp /kaggle/input/ru-fin-retrieval/*.py /kaggle/working/
   %cd /kaggle/working
   !python index_kaggle.py --acts /kaggle/input/ru-fin-retrieval/acts.jsonl.gz
   ```

   Пробный прогон на двадцати актах, чтобы убедиться, что всё загружается:

   ```python
   !python index_kaggle.py --acts /kaggle/input/ru-fin-retrieval/acts.jsonl.gz \
       --limit-acts 20 --out /kaggle/working/test
   ```

4. Скачать папку `/kaggle/working/embeddings` и положить её в проект
   как `data/embeddings`. Структура должна получиться такая:

   ```
   data/embeddings/<нарезка>/<модель>/vectors.npy
   data/embeddings/<нарезка>/<модель>/ids.txt
   data/embeddings/<нарезка>/<модель>/meta.json
   ```

## Что именно считается

Основная таблица — на базовой нарезке, пятью моделями:

| модель | размерность | зачем |
|---|---:|---|
| BAAI/bge-m3 | 1024 | рабочая лошадка |
| intfloat/multilingual-e5-large | 1024 | ради проверки префиксов `query:`/`passage:` |
| Qwen/Qwen3-Embedding-0.6B | 1024 | вектор режется без переобучения |
| deepvk/USER-bge-m3 | 1024 | bge-m3, дообученная на русском |
| ai-forever/FRIDA | 1536 | русскоязычная, своя схема префиксов |

Абляции по нарезке — на `multilingual-e5-small`: там сравниваются между собой
конфигурации нарезки, а не модели, и брать для этого самую тяжёлую модель
значило бы потратить шесть часов вместо одного.

Если какая-то модель не загрузится, скрипт это напечатает и пойдёт дальше:
одна неудача не рушит весь прогон. Посчитанное не пересчитывается, так что
после сбоя ноутбук можно просто запустить заново.

## Сколько это весит

Загрузить на Kaggle — около 20 МБ. Скачать обратно — около 1 ГБ:
матрицы сохраняются в float16, для косинусной близости точности хватает.
